This plugin helps you to calculate profit for your WooCommerce products.

== Description ==

The **PCW - Profit Calculation** plugin allows shop administrators to set a "Buying Price" (cost price) for their products. When an order is placed, this cost is recorded in the order item metadata to ensure historical accuracy.

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/pcw-profit-calculation/`.
2. Run `composer install`.
3. Activate the plugin through the 'Plugins' screen in WordPress.
4. Go to any Product > General Tab and set the "Buying Price".
